Orchid Rescue Thumbnail Index

Summary

The Orchid Rescue index is now a visual collection. Published orchids show a photographic thumbnail with their name underneath, while unfinished profiles use a matching Coming Soon tile.

Accomplishments

  • Added current-condition thumbnails for all five published orchids.
  • Added consistent placeholders for all four draft orchids.
  • Preserved direct profile and Coming Soon routing.
  • Added responsive desktop and two-column mobile layouts.
  • Verified image loading and the production build.

Lessons Learned

  • A consistent thumbnail frame lets finished and unfinished profiles share one gallery without making the draft entries look accidental.

Next Steps

  • Publish and verify the updated collection page.
