# BradCooke.com

BradCooke.com is a first-class Abbey project and owns its website source,
personal content, museum exhibits, hobbies, and public Orchid Rescue output.

Canonical plant workspaces and plant tooling remain in Abbey Root. Plant
Markdown, sanitized public images, and publication manifests in this repository
are generated imports. Correct plant facts in Abbey Root, then run the
configured plant publishing workflow from there.

Use the standard Abbey session workflow. Build and validate this site from this
repository. Do not use Abbey Root's site as a BradCooke.com publishing source.

Publishing is a separate, explicit action. A local build does not authorize a
push or GitHub Pages deployment.
